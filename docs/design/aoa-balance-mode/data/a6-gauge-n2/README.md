# A6 gauge — N-2 unused-gas penalty decomposition, local anvil control

**Rehearsal on a local anvil chain (stable foundry, Cancun). Not A6, not a sample, not Amsterdam numbers.**
It shows that the decomposition added for the DSR N-2 ruling (CC-127 dc549c74) works on real traces, and that its
independent cross-check fires. Driver: `n2-run.sh.txt`. Collector HEAD `be6fcbe1`, `collectorDirty: false`.

## What is decomposed

EntryPoint v0.7 (`EntryPoint.sol:718-730`) adds `penalty = floor((L − E) · 10 / 100)` when `L > E`, with
`L = callGasLimit + paymasterPostOpGasLimit` and `E = actualGas_prePenalty − preOpGas`; `actualGasUsed` in
`UserOperationEvent` includes it.

- `preOpGas` is **read**, exactly, from the `innerHandleOp` calldata in the callTracer trace (`opInfo.preOpGas`,
  word 14), bound to the op by its userOpHash, sender, nonce, paymaster and limits.
- `E` and `penalty` are **derived** by inverting `actualGasUsed = preOpGas + E + penalty`. This is algebra on the
  EntryPoint formula, not a measurement: the reconstruction identity holds by construction. When
  `(L − E) mod 10 = 0` two adjacent `E` fit; such attempts are reported as `bounded` (width 1 gas), never as exact.
- **Independent cross-check** (in `negative-controls/n2-penalty-anvil.sh`): the callTracer `innerHandleOp` frame
  `gasUsed` must exceed the derived `E` by a small positive tail (the work after the penalty: event, deposit
  update). Bound: `0 < tail < 20,000`.

## Results (`n2-control.out`)

30 attempts (10 triplets), 30 decomposed exactly, 0 bounded, 0 failures. Values are identical across
triplets except the first SP and TPM ops (cold storage):

| arm | L (call + postOp limit) | actualGasUsed | preOpGas | E | **penalty** | tail |
|---|---:|---:|---:|---:|---:|---:|
| SP (first op) | 300,000 | 452,682 | 309,198 | 126,094 | 17,390 | 5,456 |
| SP | 300,000 | 387,702 | 274,998 | 91,894 | **20,810** | 5,456 |
| VPM | 150,000 | 120,575 | 101,407 | 4,632 | **14,536** | 5,392 |
| TPM (first op) | 220,000 | 177,230 | 140,420 | 16,456 | 20,354 | 5,395 |
| TPM | 220,000 | 160,130 | 123,320 | 16,456 | **20,354** | 5,395 |

The penalty is a large share of the arm differences: for VPM it is 3.1× the execution gas. This is why
`actualGasUsed` cannot be compared across arms as mechanism cost, and why the DSR ruling also asks to calibrate the
limits to measured upper bounds before sampling (not done here; these are the collector's current limits).

## Controls

| run | expected | result |
|---|---|---|
| decomposition, live re-derivation vs archive | exit 0 | exit 0 (`n2-control.out`) |
| mutation: `preOpGas` read from word 13 | red | exit 1, 30/30 `stored exact claim disagrees` (`mut-preop.*`) |
| same mutation, stored claims stripped | red, by the tail check alone | exit 1, 30/30 `innerHandleOp tail out of range` (`mut-preop-noclaim.*`) |
| no mutation, stored claims stripped | exit 0 | exit 0 (`noclaim.out`) |

The third row is what shows that the cross-check is load-bearing on its own: without it, a wrong `preOpGas` read
consistently at collection and at re-derivation would pass.

## Not verified

- Amsterdam; the Sepolia target; a run with calibrated limits.
- `postOpReverted` and other fallback paths (the decomposition reports them as unavailable).
- The tail bound is a sanity bound from these three arms, not a derived constant.

The validator accepts the run (`validator.json`, exit 0) with the note `U-6 stake gate not applied: non-conformant
run`. `baselines.anvil.json` has the anvil dev signer key redacted (`baselines.pre-redaction.sha256`). The
`.noclaim.jsonl` input is regenerated by the driver and not archived. `shasum -a 256 -c EVIDENCE.sha256`.
