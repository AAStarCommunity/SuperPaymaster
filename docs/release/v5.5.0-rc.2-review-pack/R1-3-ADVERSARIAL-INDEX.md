# Reviewer 1, Major Comment 3: adversarial evidence index

**Decision 2: bounded allowance.** The user can opt into a capped automatic allowance for a listed non-SP spender; an SP cannot use `transferFrom` or `burn(from)` against another account, even with an explicit ERC-20 approval. Balance-mode sponsorship instead reserves the user's xPNTs at validation and burns at most the admitted reservation at settlement. This is a risk argument and test index, not a claim of safety on a public chain. The six requested classes follow [the final spec](../../design/aoa-balance-mode/03-final-spec.md) and [D3 traceability](../../design/aoa-balance-mode/D3-traceability.md).
